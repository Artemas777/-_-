# Artem / Digital — демо-сайт-визитка

Статический адаптивный лендинг на HTML, CSS и JavaScript. Не требует сборки, Node.js или установки зависимостей.

## Запуск локально
Откройте `index.html` в браузере. Для корректной проверки переходов можно использовать Live Server в VS Code.

## Публикация через GitHub Pages
1. Создайте новый публичный репозиторий на GitHub.
2. Загрузите в корень репозитория все файлы из этой папки.
3. Откройте **Settings → Pages**.
4. В разделе Build and deployment выберите **Deploy from a branch**.
5. Выберите ветку `main` и папку `/ (root)`, нажмите Save.

Также проект можно импортировать в Vercel как статический сайт.

## Что заменить перед публикацией
- В `index.html` замените `hello@example.com` на реальную ссылку или контакт.
- При добавлении Telegram измените `href` у `.contact-button` на `https://t.me/ваш_username` и удалите демонстрационный обработчик в `script.js`.
- При необходимости обновите имя, описание и метаданные в `<head>`.

## Структура
- `index.html` — содержание и секции сайта.
- `styles.css` — дизайн, адаптивность и анимации.
- `script.js` — прелоадер, анимации появления и взаимодействия.
- `404.html` — страница ошибки с возвратом на главную.
- `favicon.svg` — иконка вкладки.

## Примечания
Шрифты загружаются из Google Fonts; при недоступности сети используются системные запасные шрифты. Учитывается настройка `prefers-reduced-motion`.
